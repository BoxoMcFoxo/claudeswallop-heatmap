An experiment to observe whether an essay-shaped text extruded from an LLM will exhibit consistent sentence similarity across a heatmap.

Results viewable at: [https://boxomcfoxo.github.io/claudeswallop-heatmap/](https://boxomcfoxo.github.io/claudeswallop-heatmap/)

Several control comparisons were also run, but the best comparator, an earnest human-authored essay on the same topic using the same three sources, is something that I don't really have time to compose.

If you wish to do so, or otherwise wish to iterate on this methodology, feel free!
